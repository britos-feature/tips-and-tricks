
## ***`basename`***

O comando **`basename`** serve para **extrair apenas o nome do arquivo ou diretório** a partir de um caminho completo

`basename CAMINHO [SUFIXO]`

- **`CAMINHO`** → é o caminho completo do arquivo ou diretório.
- **`SUFIXO`** (opcional) → se você passar, ele remove essa parte do final do nome.
