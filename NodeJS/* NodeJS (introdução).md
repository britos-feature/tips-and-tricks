
Node.js é um **runtime** JavaScript baseado no motor **V8** do Chrome, que permite executar JavaScript no **servidor**. Ou seja, com Node.js, você pode usar JavaScript para construir aplicações **back-end**, ao invés de apenas no navegador.
<br>
## Principais características do Node.js:

- **Event-driven e assíncrono**: usa um modelo baseado em eventos e I/O não bloqueante, o que significa que pode lidar com muitas requisições simultaneamente sem travar.
  
- **Executa JavaScript fora do navegador**: permite usar JavaScript para criar servidores, APIs, automação, etc.
  
- **Single-threaded com event loop**: funciona com uma única Thread gerenciando múltiplas conexões de forma eficiente.
   
- **Gerenciador de pacotes (NPM)**: inclui o **NPM (Node Package Manager)**, que permite instalar milhares de pacotes e bibliotecas prontas para uso.
<br>
### **Módulos**

  Os **módulos** no Node.js são blocos reutilizáveis de código que ajudam a organizar e estruturar melhor as aplicações. O Node.js já vem com vários **módulos nativos (built-in)**, e também permite que você crie seus próprios módulos ou use pacotes de terceiros do **NPM**.
