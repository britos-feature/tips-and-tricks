# Anotações uso diário

## Git log

Visualização de **commits** realizados


```bash

### 📜 Ver histórico completo de commits
git log

### 📄 Versão resumida (mais prática)
git log --oneline

### 👤 Commits de um autor específico
git log --author="Seu Nome"

### 📁 Commits que alteraram um arquivo específico
git log -- caminho/do/arquivo.ext

```
